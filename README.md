# CHZZK Auto Translation (치지직 실시간 번역 자막)

치지직 방송에서 들리는 언어를 자동으로 알아듣고, 원하는 언어의 자막으로 실시간 번역해 영상 위에 띄우는 크롬 확장 프로그램입니다. 기본 설정은 API 키 없이 무료로 동작합니다.

- 🇯🇵 CHZZK配信で話されている言語を自動で聞き分け、選んだ言語の字幕にリアルタイムで翻訳します。APIキー不要・無料。
- 🇺🇸 Auto-detects the spoken language on CHZZK live streams and shows real-time subtitles in the languages you choose. Free, no API key.

한국어 · 日本語 · English 스토어 설명 전문은 [STORE_LISTING.md](STORE_LISTING.md)에 있습니다.

## 설치 (개발자 모드)
1. [Releases](../../releases/latest)에서 `chzzk-live-translator.zip`을 받아 압축을 풉니다.
2. 크롬에서 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → `chzzk-live-translator` 폴더를 선택합니다.
   (1.0.0을 설치했었다면 카드의 새로고침 버튼을 누르거나 지우고 다시 로드하세요.)

## 사용
- 시작/중지: 방송 화면의 **번역 자막** 패널 → **번역 시작**, 확장 아이콘 → **번역 시작**, 또는 **Alt+Shift+T**
  - 패널에서 시작하면 영상 요소의 소리를 직접 받아 쓰므로 탭 소리가 꺼지지 않습니다.
- 설정 패널은 마우스가 벗어나면 자동으로 닫힙니다 (슬라이더를 끄는 중에는 유지).
- 실시간 설정: 플레이어 컨트롤 바의 **번역 자막** 버튼, 또는 플레이어 톱니바퀴 메뉴의 **번역 자막** 항목
  - 입력 언어(자동 감지 또는 고정), 자막 언어(최대 4개, 고른 순서대로 표시), 원문 표시
  - 자막 크기(12~48px, ± 버튼), 배경 진하기, 표시 줄 수, 위치 초기화, 중지
  - 바꾸는 즉시 화면에 반영되고 자동 저장됩니다.
- 설정 언어: 팝업 오른쪽 위 또는 패널의 **설정 언어**에서 자동·한국어·日本語·English 선택 (자동은 브라우저 언어)

## 언어
- 듣는 언어는 **한국어**로 고정됩니다. 말이 쉬지 않고 이어져도 약 3초마다 끊어 번역합니다.
- 자막 언어: 한국어·日本語·English 중에서 고릅니다(여러 개면 고른 순서대로 표시).
- **원문도 함께 보기**를 켜면 자막 맨 위에 들리는 대로 받아 적은 원문이 작게 나옵니다. 말하는 도중에는 지금 받아 적고 있는 글자가 기울임꼴로 실시간 표시됩니다.
- 크롬 내장 번역 모델은 클릭할 때만 내려받을 수 있어서, 모델이 없는 언어 쌍은 Google 번역으로 대신 번역합니다.

## 노래 자막 (테스트)
패널·팝업의 **노래 자막 (테스트)** 버튼을 누르면:
- 스텔라이브 전 멤버와 포테땅(`langs.js`의 `SONG_CHANNELS`, 15곳)을 모두 팔로우해야 사용할 수 있습니다. 치지직 페이지 안에서 사이트와 같은 로그인 상태로 내 팔로우 목록(없으면 채널별 내 팔로우 정보)을 조회하며, 하나라도 팔로우하지 않았으면 켜지지 않고 아직 팔로우하지 않은 채널을 링크로 보여 줍니다. 로그인하지 않았거나 조회에 실패해도 켜지지 않습니다. 확인 결과는 5분 동안 기억하고, 방송 화면을 새로 열 때 노래 자막이 켜져 있으면 다시 확인해 팔로우를 끊었으면 끕니다.
- 듣는 언어가 **한국어·English·日本語 자동**으로 바뀝니다. 말소리 구간마다 작은 Whisper(tiny, 약 40MB)가 셋 중 어느 언어인지 매번 확인하고, 그 구간 판별이 80% 이상 확실하면 그 구간은 그 언어로 받아씁니다(노래 중간에 영어 가사가 섞여도 바로 따라감).
- **노래 입력 언어**: 노래 자막을 켜면 버튼 아래에 '자동 · 한국어 · 日本語 · English'가 나옵니다. 자동이 기본이고, 하나를 고르면 감지 없이 그 언어로만 받아씁니다.
- 원문(위층, 크게)과 번역(아래층)을 **한 자막으로 묶어** 가운데 정렬해 보여 줍니다. '표시 줄 수'에서도 이 묶음을 한 줄로 셉니다. 받아 적는 동안에는 들리는 대로 적히는 원문이 흐리게 실시간으로 나오고, 문장이 완성되면 아래층에 번역이 붙습니다. 번역은 고른 자막 언어마다 붙습니다. 입력 언어와 같은 자막 언어가 있으면 원문을 두 번 쓰지 않고 그 자막 줄 하나로만 보여 줍니다.
- 고성능 Whisper(large-v3-turbo)로 인식합니다. API 키가 있으면 Whisper API, 없으면 이 컴퓨터의 GPU(WebGPU, 처음 한 번 약 760MB)를 씁니다. GPU가 없으면 기본 모델로 인식하고 안내를 띄웁니다.
- 다시 누르면 한국어 듣기로 돌아갑니다. 방송 중에 켜고 꺼도 번역은 멈추지 않습니다.

## 무료 동작 방식
| 단계 | 1순위 | 자동 대체 |
|---|---|---|
| 음성 인식 | 크롬 내장 Web Speech (탭 오디오 직접 입력, Chrome 133+) | 브라우저 안에서 도는 Whisper (transformers.js) |
| 번역 | 크롬 내장 Translator API (온디바이스, Chrome 138+) | Google 번역 무료 엔드포인트 |

- 브라우저 Whisper는 처음 한 번 모델을 내려받습니다. GPU(WebGPU)가 있으면 whisper-small(약 330MB), 없으면 whisper-base(약 80MB)를 쓰며 이후에는 캐시에서 바로 불러옵니다.
- Groq/OpenAI API 키를 넣으면 더 정확한 Whisper API와 말투를 살린 AI 번역도 선택할 수 있습니다 (고급 설정 → API 키 입력란 항상 보기).

## 구조
- `offscreen.js` : 탭 오디오 캡처 → 입력 언어 감지 → 인식 엔진 선택/자동 전환 → 번역
- `lid.js` : Whisper 언어 판별, 언어 전환 안정화(LangTracker), 텍스트 언어 추정
- `langs.js` : 지원 언어 표와 엔진별 언어 코드, 이전 버전 설정 이전
- `pcm-worklet.js` : AudioWorklet 으로 오디오 블록 수집 (Whisper 계열용)
- `lib/` : transformers.js 4.3.2 와 ONNX Runtime WASM (로컬 번들, 원격 코드 없음)
- `content.js` : Shadow DOM 자막 오버레이 (전체화면 대응, 드래그 이동)
- `background.js` : 오프스크린 문서 수명 관리 및 메시지 중계
- `popup.html / popup.js` : 설정과 시작/중지
